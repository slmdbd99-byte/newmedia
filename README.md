# 基于SEI的时尚传播与新媒体运营课程数智平台

单文件网站（`index.html`），无需服务器和数据库，也不依赖任何外部库，打开即可使用。

## 一、单机使用
双击 `index.html`，用 Chrome 或 Edge 打开。数据保存在本机浏览器（localStorage）中。

## 二、一键发布（任选一种）
**GitHub Pages**
1. 新建一个公开仓库，把本文件夹中的全部文件（含隐藏的 `.github`、`.nojekyll`）上传到 `main` 分支。
2. 打开仓库的 Settings → Pages，Source 选 **GitHub Actions**。
3. 推送后，内置工作流 `.github/workflows/pages.yml` 会自动部署，地址形如 `https://<用户名>.github.io/<仓库名>/`。

**Gitee Pages / Netlify Drop / Vercel / Cloudflare Pages**：直接上传 `index.html` 即可，没有构建步骤。

## 五、AI 功能说明
- **默认：本地规则引擎**。离线可用，回复中会标明“规则引擎·未连接大模型”。
- **本地大模型（数据不出本机）**：支持 Ollama、LM Studio 和浏览器内置模型（WebGPU），详见单机版中的《本地AI使用说明》。本地AI请使用单机版运行；在线版的浏览器可能禁止网页访问本机服务。
- **可选：接入云端大模型**。在“AI助手与留痕”页填写接口地址、模型名和 API 密钥，支持 OpenAI 兼容接口（包括多数国内厂商）和 Anthropic Messages 接口；识图功能需要选用支持图像的模型。
- 密钥只保存在本机浏览器。公开部署时，建议由教师搭建一个代理接口，学生只填代理地址。有些接口不允许浏览器直接调用（跨域限制），调用失败时系统会自动回退到规则引擎，并在回复中注明。
- 框图的准确性机制：每条流向都附原文依据，并自动核对能否在原文中找到；还做结构校验（资金是否流入平台、价值是否传到需求方、有无孤立节点）；可拖动方框调整位置，点击方框或箭头修改名称、角色、起点、终点、类型和说明，增删参与方与流向，导出可编辑 SVG。
- 四条使用规范：AI 不直接给答案；来源必须核查；全程留痕（提示词、AI稿、核验状态）；终裁权在人。
